# Notes for coding agents

Follow [CONTRIBUTING.md](CONTRIBUTING.md): its rules, checks and release steps apply to you.

- Run `bun run check` before saying work is done, and report failures as they are.
- `HANDOFF.md` records the design decisions and their reasons; read it before changing the reader, the PDF or note sources, or the sidecar protocol.
- The plugin is tested in Obsidian by hand; say which changes still need that.
- Don't create releases, push tags or change repository settings unless asked.
