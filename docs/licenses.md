## Optional Piper restrictions

The current English catalog has **28 Kokoro and 38 Piper entries**. All 37 available Piper model cards were checked at the pinned repository revision recorded in [piper-licenses.md](piper-licenses.md); the remaining Saikat entry has no card in that repository. Ryan, Semaine, HFC and L2-ARCTIC cards list noncommercial dataset terms. Other cards contain attribution/share-alike requirements, Lessac research terms or indirect license links. Dataset terms and weight/output terms are distinct; the cards do not establish a uniform license for every derivative.

These are optional downloads chosen by the person, not assets redistributed in Edge Voice's plugin or engine. The voice picker points to these restrictions before a person gets another voice. Use the cleared LibriVox input or Kokoro for project demos; don't use a restricted Piper voice for promotional audio. If a future release bundles model weights, publishes an audio corpus, or claims all voices are commercially unrestricted, this inventory is **not sufficient clearance**: resolve each affected source grant first. Saikat and unclear G2P weight terms remain specific upstream provenance gaps, not audited passes.

## Feynman and brand assets

**No Richard Feynman audio is included.** [Caltech's Feynman site](https://www.feynmanlectures.caltech.edu/) allows online reading/listening but explicitly withholds download rights. Freely viewable BBC/TED/YouTube copies do not establish a redistribution license. No specifically cleared NASA/Feynman recording was found, and NASA's general media policy also retains third-party/publicity-rights conditions. A suitable source-specific permission would be needed before replacing the cleared STT input.

[Obsidian's brand guidelines](https://obsidian.md/brand) ask that its logo not be edited, recolored or reconfigured, identify the icon/name as trademarks, and direct commercial asset users to contact Obsidian. The maintainer selected `edge-voice-social-preview-purple-v4.png` as the banner. The repository copy preserves its chip/crystal and existing TTS/STT text exactly; no additional logo editing was performed. Selecting it does not establish trademark permission: confirm this promotional use against those guidelines before publishing. The alternative original speech-emblem banner is retained only in local scratch files. Screenshots show the actual application in context and must not imply endorsement. Keep third-party trademarks separate from our own MIT artwork license.

## Verification record

- English ASR manifest: 24 model files, pinned official HTTPS revision, sizes and SHA-256. The release build includes the manifest and MIT notice; offline model loading checks managed files before native parsing. File integrity establishes identity, not licensing by itself.
- No ASR, TTS voice, dataset or original full audiobook is added to the repository or plugin release. The short cleared demo excerpt is the only new redistributed source audio.
- Dictation adds no Python dependencies. The weekly dependency-advisory scan covers the engine locks; the custom Mac wheels, native libraries and model files aren't covered by it (see CONTRIBUTING's Dependency advisories).
- Review these sources again if model/runtime/voice pins change. Do not copy an unverified upstream model into our releases based only on its availability for download.
